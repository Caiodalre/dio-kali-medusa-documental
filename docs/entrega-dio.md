# Publicação e entrega

## Publicar no GitHub

1. Extrair o arquivo ZIP do projeto.
2. Criar no GitHub um repositório público chamado `dio-kali-medusa-documental` ou outro nome de sua preferência.
3. Escolher **Add file → Upload files** e enviar o conteúdo da pasta `projeto-medusa`, mantendo a estrutura das subpastas. O `README.md` deve ficar na raiz do repositório.
4. Confirmar o envio e abrir a página principal para verificar a formatação e os links internos. Se o arquivo `.gitignore` não aparecer no envio, adicioná-lo separadamente.
5. Copiar o endereço real do repositório e inseri-lo no campo de entrega da DIO.
6. Conferir e concluir as videoaulas exigidas pelo desafio antes de enviar.

Repositório público: https://github.com/Caiodalre/dio-kali-medusa-documental

## Descrição pronta para a DIO

Projeto documental sobre auditoria de senhas com Kali Linux e Medusa, abordando força bruta em FTP, automação de tentativas no DVWA e password spraying em SMB. O repositório reúne planejamento de laboratório isolado, wordlists didáticas, exemplos de comandos, critérios de validação e recomendações de prevenção. A entrega segue a modalidade de estudo permitida pelo desafio: não foram executados ataques nem produzidas evidências práticas.
